Como encontrar seletores CSS?
  1. Abra a página da notícia no navegador
  2. Pressione F12 ou clique com botão direito → Inspecionar
  3. Clique no ícone de seleção e passe sobre o elemento desejado
  4. No código HTML destacado, procure por:
    • class="nome-da-classe" → use .nome-da-classe
    • id="identificador" → use #identificador
    • Tag HTML → use diretamente: h1, article, etc
  5. Combine quando necessário: article .content p
